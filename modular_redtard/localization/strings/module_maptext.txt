# Надписи над картой (maptext), которых панель чата не видит: шарики
# balloon_alert и заголовки областей Рокхилла (rockhill_area_text). Их переводит
# сервер для каждого зрителя (localization/maptext.dm) тем же движком, что и
# панель (localization/translate.dm): точная строка из этого файла или из общих
# файлов фрагментов, затем шаблоны этого файла, module_patterns.txt и
# patterns.txt. Строка внутри тегов (<font>, <i>) переводится по кускам между
# тегами. Не нашлось — остаётся английской. Строже, чем в чате: шаблон, после
# которого в строке остался бы английский (захват $N|падеж, которого нет в
# таблице существительных, или английский захват $N), строку не берёт —
# «В the box пусто!» на карте не будет, будет «the box is empty!».
#
# Формат:  английское = русское
# Строка, которая начинается с "^", — шаблон: регулярное выражение, как в
# patterns.txt, $N|падеж склоняет захват N по таблице существительных.
# Шарики короткие и пишутся со строчной — так и переводить; лицо — безличное
# или первое, как в строках чата модуля.
