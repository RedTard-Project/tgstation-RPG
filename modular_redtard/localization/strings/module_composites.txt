# Имена и описания, которые игра собирает во время раунда и поэтому не находит
# ни в словаре имён, ни по типу (localization/translate.dm: rogue_russian_name(),
# rogue_russian_description()): приставка качества, «гнилое», пустая трубка,
# блюдо с едой, рукопись, книга игрока, захват, хвост описания слитка. Читает
# только сервер — в панель чата файл не идёт.
#
# Формат — как в module_maptext.txt: точная строка или шаблон с "^". Правило
# строже, чем в чате: перевод берётся, только если каждый захват с $N|падеж
# нашёлся (имя вещи — в items.txt и module_items.txt, им. падеж — ещё и этим же
# файлом), иначе имя или описание остаётся английским целиком.
# $N|падеж? — склонить, если нашлось, иначе вставить как есть (имя персонажа).
# Прилагательное к имени с неизвестным родом не пишется: качество стоит после
# имени в родительном падеже («меч тонкой работы»), как «в крови» у Вайблина.

# --- имена, которые шаблоны ниже поняли бы неверно ---
# Точная строка проверяется раньше шаблонов: руда — не «руда из железа».
iron ore = железная руда
copper ore = медная руда
tin ore = оловянная руда
silver ore = серебряная руда
gold ore = золотая руда
golden apple = золотое яблоко
iron pill = железная пилюля

# --- приставки к имени ---
# Качество ремесла (crafting/materials.dm, rogue_quality_prefix()): слитки,
# кованое, сделанное на столе, гончарное.
^ruined (.+)$ = $1|nom негодной работы
^awful (.+)$ = $1|nom скверной работы
^crude (.+)$ = $1|nom топорной работы
^rough (.+)$ = $1|nom грубой работы
^fine (.+)$ = $1|nom тонкой работы
^flawless (.+)$ = $1|nom безупречной работы
^masterwork (.+)$ = $1|nom мастерской работы
# Материал перед именем ("[материал] sword": материалы ТГ с MATERIAL_ADD_PREFIX
# и имена, которых нет в словаре целиком) — «меч из железа». Имя целиком
# ("iron sword" = железный меч) ищется раньше, так что это лишь запасной путь.
^iron (.+)$ = $1|nom из железа
^steel (.+)$ = $1|nom из стали
^blacksteel (.+)$ = $1|nom из чёрной стали
^silver (.+)$ = $1|nom из серебра
^gold (.+)$ = $1|nom из золота
^golden (.+)$ = $1|nom из золота
^bronze (.+)$ = $1|nom из бронзы
^copper (.+)$ = $1|nom из меди
^tin (.+)$ = $1|nom из олова
^wood (.+)$ = $1|nom из дерева
^wooden (.+)$ = $1|nom из дерева
^stone (.+)$ = $1|nom из камня
^glass (.+)$ = $1|nom из стекла
^bone (.+)$ = $1|nom из кости
^leather (.+)$ = $1|nom из кожи
^cloth (.+)$ = $1|nom из ткани
^silk (.+)$ = $1|nom из шёлка
# Еда (survival/food.dm, become_rotten()).
^rotten (.+)$ = $1|nom с гнилью
# Прогоревшая трубка (clothing/smoking.dm).
^empty (.*pipe)$ = $1|nom без табака
# Блюдо с едой (survival/cookware.dm).
^platter of (.+)$ = $1|nom на блюде
# Рукопись (library/writing.dm).
^(\d+) page manuscript$ = рукопись ($1 стр.)
# Захват и укус (combat/grab.dm, combat/mmb.dm): "[кто]'s [часть тела]".
# Грудь и живот — отдельно: в словаре имён вещей "chest" — сундук, "stomach" — желудок.
^(.+?)'s chest$ = грудь ($1|nom?)
^(.+?)'s stomach$ = живот ($1|nom?)
^(.+?)'s ((?:left |right )?(?:head|neck|groin|mouth|eyes?|ears?|arm|hand|leg|foot|skull|body))$ = $2|nom ($1|nom?)

# --- описания ---
# Качество слитка (crafting/materials.dm, rogue_set_ingot_quality()): к описанию
# типа дописано предложение; описание типа переводится по descriptions.txt.
It is practically scrap. = Это почти лом.
It is of dubious quality. = Качество сомнительное.
It is of notable quality. = Качество заметно выше обычного.
It is of remarkable quality. Fit for ambitious endeavours. = Качество превосходное. Годится для смелых замыслов.
^It is of exquisite quality\. It (?:yearns|begs|demands) to be turned into a masterwork\.$ = Качество изысканное. Слиток так и просится в шедевр.
# Рукопись и книга игрока (library/writing.dm, library/books.dm).
^A (\d+) page written piece aspiring to one dae become a book\.$ = Рукопись в $1 стр., что однажды надеется стать книгой.
# Только с датой Рокхилла (rockhill_date_short()): «By …» без неё бывает и
# в обычных описаниях.
^By ([^,]+), written (\d+ \S+ \d+ AP)$ = Автор — $1, написано $2
